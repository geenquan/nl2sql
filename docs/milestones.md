  不可重验）；进程内共享验证并发额度（覆盖连接/核对/探查全程，等待受期限约束；
  单进程语义）；预算改按实际 SQL 语句数核销（结构核对计入，超期证据不升级

  窗口 JOIN，不以行数估计作安全依据）；组合键去重改原生多列 DISTINCT
  （CHAR(31) 碰撞真实 MySQL 复现并修复）。
- 已知限制：数据分布漂移不会自动识别（结构漂移自动 stale；分布漂移需人工

  多进程部署不构成跨进程保证）；MariaDB 无服务端语句期限提示（客户端
  read_timeout 是放弃读取，不等于服务端取消）；编码映射类跨族类型关系需人工
  登记（origin=human），不自动召回；跨快照并发写同一逻辑键可能表现为安全侧
  409（唯一约束仲裁）。
