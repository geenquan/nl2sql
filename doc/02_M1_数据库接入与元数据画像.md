# M1 实现手册：数据库接入与元数据画像

## 1. 目标

稳定、安全地连接首版数据库（建议 MySQL），采集 Schema、表、字段、约束、索引与必要的数据画像。只读访问，不修改源库。

## 2. 输入

- 数据库类型、主机、端口、数据库名；
- 用户名和密码/密钥引用；
- 允许扫描的 Schema/表；
- 查询预算、采样规模和脱敏策略。

## 3. 输出展示形态

### 3.1 数据源卡片
展示：数据源名称、数据库类型、连接状态、最近扫描时间、Schema 数、表数、字段数、扫描状态。

### 3.2 Schema 浏览器
树状展示 `数据源 → Schema → 表`，支持搜索和过滤。

### 3.3 表详情页
展示字段名、类型、注释、主键/外键、索引、行数估计、最近画像时间。

### 3.4 字段画像卡片
展示空值率、唯一率、基数估计、样本分布、长度/数值范围、示例值（脱敏）。

### 3.5 扫描任务详情
展示进度、成功/失败表数、耗时、错误原因、重试操作。

## 4. 推荐接口

- `POST /sources`
- `POST /sources/{id}/test`
- `POST /sources/{id}/scans`
- `GET /scans/{job_id}`
- `GET /sources/{id}/schemas`
- `GET /tables/{table_id}`
- `GET /tables/{table_id}/profile`

凭证不能通过读取 API 返回。

## 5. 实现步骤

1. 定义统一 `DataSourceConnector` 接口；
2. 实现 MySQL Connector；
3. 使用 SQLAlchemy Inspector 或数据库元数据表读取结构；
4. 将原生结构映射到统一数据模型；
5. 采集主键、外键、唯一约束、索引；
6. 采集行数估计与列画像；
7. 实现抽样与脱敏；
8. 将元数据写入元数据库并支持快照；
9. 实现扫描任务状态、重试和错误记录；
10. 实现增量 Schema 变更检测。

## 6. 画像策略

- 优先使用数据库统计信息和采样；
- 对大表避免默认精确扫描所有字段的 `COUNT(DISTINCT)`；
- 对候选关联字段再执行更精确验证；
- 采样可采用主键区间、时间区间或类别分层；
- 统计摘要优先于原始样本；
- 明确 NULL、空字符串、默认值与异常占位符的区别。

## 7. 安全要求

- 只读账户；
- 连接超时与查询超时；
- Schema/表白名单；
- 凭证不进入日志或模型上下文；
- 样本脱敏；
- 任务扫描预算和并发限制；
- 数据源之间隔离。

## 8. 验收

- [ ] 可以测试连接并给出安全错误信息；
- [ ] 可以列举指定 Schema、表、字段和约束；
- [ ] 重复扫描可识别结构变化；
- [ ] 大表画像遵守查询预算；
- [ ] 样本值按规则脱敏；
- [ ] 单表失败不导致整库扫描不可恢复；
- [ ] 凭证不被返回或写入日志；
- [ ] 页面/接口展示实际扫描结果，而不是静态假数据。

## 9. 完成后演示

1. 添加测试数据源；
2. 测试连接；
3. 启动扫描；
4. 查看 Schema 与表列表；
5. 打开一张表的字段画像；
6. 人为制造权限错误，验证失败提示；
7. 展示扫描任务日志。
