# 企业数据库自动理解与 NL2SQL 实现手册包

本目录是阶段实施手册；当前代码、环境和验证状态以 `../docs/` 为准。
开始开发前先阅读 [配置说明](../docs/configuration.md)、[开发交接报告](../docs/development-status.md)
和 [Claude 开发指南](../docs/claude-code-guide.md)。当前使用现有 Conda `nl2sql` / Python 3.13.18，
不要依据历史说明重建环境或覆盖用户已更新的 `.env` 与 `.env.example`。

建议阅读顺序：

1. `00_总路线与里程碑指导手册.md` — 项目目标、总体架构、M0–M8 里程碑、统一交付规范。
2. `01_M0_工程骨架与评测集.md` — 建立可运行工程与评测基线。
3. `02_M1_数据库接入与元数据画像.md` — 数据源连接、Schema、字段画像。
4. `03_M2_字段语义理解.md` — 字段和表用途的语义推断。
5. `04_M3_跨表关系发现与验证.md` — 核心关系发现算法与验证。
6. `05_M4_业务实体与语义层.md` — 实体、指标、粒度与查询路径。
7. `06_M5_数据清洗与宽表生成.md` — 视图/宽表生成、质量校验。
8. `07_M6_NL2SQL与结果验证.md` — SQL 生成、安全执行和结果评估。
9. `08_M7_查询智能体组装与产品化.md` — 智能体工具编排、权限和运维治理。
10. `09_附录_Claude_Code任务模板与验收清单.md` — 可复制的 Claude Code 任务模板。

每个里程碑必须完成“实际输入 → 实际输出 → 测试 → 验收”，不允许用静态 mock 结果替代真实实现。首版建议只支持 MySQL，先在一个业务主题上跑通闭环，再扩展数据库和行业。
